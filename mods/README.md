# Mods

Optional add-ons for the Serpantinum shell. Each one has its own idempotent `install.sh`, so
re-run it after a shell update.

- `pet/`: a pixel-art desktop cat (`SUPER+K` / `SUPER+SHIFT+K`). See `pet/README.md`.
- `lofi/`: toggles a calm lofi radio stream with `SUPER+-` (needs `mpv`). Streams are
  third-party internet radio (laut.fm, SomaFM); edit `STREAMS` in `lofi/lofi-toggle` to change them.
